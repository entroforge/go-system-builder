这些是审查视角，不是八项必做任务。Main / 专业审查者判断实际相关性；Hook不作相关性分类。

## 3. 阻断与非阻断风险

显示真实问题、实际影响、责任及可落实处理。未完成与阻断如实保留，不以总体结论掩盖。
只在有真实剩余风险或技术债时报告，不强制新 ticket、恢复引用或来源登记证明。
