## Cancel order — §1

Validate outgoing requests and received data against the shared definitions.
Consume the [cancellation protocol](SYNC-001.md#cancel-order): a 200 result may
be reported as cancelled; a 409 must be treated as a business rejection and must
not be shown as success. Do not invent local wire types or mock state values.
